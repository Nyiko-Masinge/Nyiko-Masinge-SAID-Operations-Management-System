# SAID Ops Supervisor Web

Integrated Next.js/TypeScript supervisor application with Firebase Auth, durable workforce/templates/areas, trusted publication, genuine monitoring, operational history and archive. Next Node APIs use server-only Firebase Admin credentials. Web hosting is prepared for Vercel. The same trusted boundary accepts staff mobile progress actions and atomically writes progress, history and persistent notifications. Firebase Spark Auth/Firestore requires no production Functions or Firebase billing.

Use Node 22.23.3/npm 10.9.9: `npm ci`, then `npm run dev` from this directory. Configure ignored `.env.local` from `.env.example`; sign in with a provisioned supervisor Employee ID/password. Select Firestore modes explicitly for integrated behavior. Local fixture modes remain available; no credential-free prototype login exists.

Checks: `npm run lint`, `npm run build`, and the shared root release gates.
